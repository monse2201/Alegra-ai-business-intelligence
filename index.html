05 · Capa semántica lista para agentes

Diccionario de Métricas

Las definiciones compartidas permiten que dashboards, analistas y agentes de IA respondan de forma consistente la misma pregunta de negocio.

MRR

Ingreso Recurrente Mensual
SUM(active_subscription_monthly_value)

NRR

Retención Neta de Ingresos
(MRR inicial + Expansión − Contracción − Churn) / MRR inicial

CAC

Costo de Adquisición de Clientes
Inversión en adquisición / nuevos clientes

Logo Churn

Tasa de pérdida de clientes
Clientes perdidos / clientes al inicio del período

Prueba → Pago

Conversión de prueba
Pruebas convertidas a pago / pruebas elegibles

LTV

Valor de vida del cliente
ARPA × margen bruto / churn de ingresos
Por qué importa para IA: an agent should not invent what “churn” or “MRR” means. The semantic layer supplies definitions, owners, grains and calculation logic first.
